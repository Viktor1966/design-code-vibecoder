# Дизайн-код вайбкодера

Интерактивная браузерная версия по загруженному PDF «Дизайн-код вайбкодера» (Clockwork School).

## Что внутри
- 30 инструментов в пяти разделах: Почерк, Каркас, Механика, Системы, Калибровка.
- Поиск по названию, английскому названию, описанию и тексту команды.
- Фильтры по разделам.
- Копирование каждой команды.
- Выбор инструментов и автоматическая сборка блока «Как выглядит».
- 6 быстрых сборок под типовые задачи.
- Фильтр «Защита от шаблона».
- Локальное сохранение выбранных инструментов и названия проекта в браузере.
- Адаптивный тёмный интерфейс.

## Запуск на компьютере
Откройте `index.html` в браузере. Сервер и сборка не требуются.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите `index.html`, `README.md` и `.nojekyll` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Дождитесь публикации и откройте ссылку, указанную в Pages.

## Примечания
- Выбранные инструменты хранятся в `localStorage` данного браузера и не синхронизируются между устройствами.
- Шрифты Google Fonts загружаются из сети; при отсутствии сети используются системные резервные шрифты.
- Тексты команд переданы по содержанию PDF; в веб-приложении они организованы в интерактивную библиотеку и конструктор промта.
